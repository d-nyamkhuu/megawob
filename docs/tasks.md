# MegaWoB tasks

Generated by `python -m megawob.describe --markdown docs/tasks.md`; do not edit by hand.

- Every task, its scenarios, the inputs it accepts and two sample instructions per scenario.
- The instruction is the goal text: BrowserGym `obs["goal"]` after `reset()`, OpenEnv `observation.goal`.
- Each task also runs as `<task>.heldout`, `<task>.<site>` and `<task>.eval-<name>` ([task names](glossary.md#task-names)).
- Input the task does not accept (a key press or the wheel where only the pointer is listed) has no effect and is reported in `obs["last_action_error"]` ([`undeclaredInput`](randomization.md#drag-steps-and-undeclared-input)).

## Eval perturbations

`<task>.eval-<name>` runs the training designs with one factor set to values training never uses. A perturbation marked with a task feature is registered only for tasks that have it. [randomization.md](randomization.md) shows what each parameter does.
